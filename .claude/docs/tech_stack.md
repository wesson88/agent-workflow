# 技术栈说明（Tech Stack Overview）

本文件用于记录本项目所采用的主要技术栈及其用途。

## 1. 后端（Backend）
- Python 3.x：主业务逻辑与自动化脚本
- Flask/FastAPI（可选）：RESTful API 服务
- SQL/NoSQL 数据库：数据持久化

## 2. 前端（Frontend）
- HTML5/CSS3/JavaScript：基础页面开发
- React/Vue（可选）：现代前端框架

## 3. 自动化与工具
- Bash/Python 脚本：自动化运维与批量处理
- VS Code：主力开发环境
- Git：版本控制

## 4. 其他
- Markdown：文档与规则说明
- JSON：配置与状态同步
