# status.json 字段说明

本文件用于解释 `status.json` 配置文件中各字段的含义和用途。

## 字段说明

- **schema_version**
  - 状态文件的版本号。
- **project_name**
  - 项目名称。
- **system_state**
  - 系统整体状态（如 normal、blocked 等）。
- **block_reason**
  - 系统阻塞时的原因说明。
- **recursion_config**
  - 递归相关配置。
  - **max_depth**：递归最大深度。
  - **current_depth**：当前递归深度。
  - **halt_on_failure**：遇到失败时是否中止递归。
  - **consecutive_failures_limit**：单技能连续失败的最大容忍次数。
- **skill_registry**
  - 技能注册表，记录各技能的状态。
  - **chief_architect / technical_lead / dev_backend / dev_frontend**：技能名称（可扩展）。
    - **status**：当前技能状态（见 status_enum）。
    - **version**：技能版本号。
    - **last_run**：上次执行时间。
    - **last_patch_timestamp**：上次补丁时间（如有）。
    - **error_count**：累计错误次数。
    - **consecutive_failures**：连续失败次数。
    - **last_output_path**：最近一次输出的路径（如有）。
- **active_tasks**
  - 当前激活的任务列表。
  - **task_id**：任务编号。
  - **assignee**：分配到的技能。
  - **description**：任务描述。
  - **status**：任务状态（如 pending、running、done 等）。
  - **priority**：优先级。
  - **created_at**：创建时间。
  - **dependencies**：依赖任务列表。
  - **outputs**：任务输出。
  - **retry_count**：重试次数。
- **audit_log**
  - 审计日志，记录操作历史。
  - **timestamp**：操作时间戳。
  - **from_skill**：发起操作的技能。
  - **target_skill**：被操作的技能。
  - **action**：操作类型。
  - **task_id**：关联任务编号（如有）。
  - **result**：操作结果。
  - **details**：详细说明。
- **status_enum**
  - 允许的技能状态值集合：
    - `idle`：空闲，等待任务
    - `busy`：正在执行任务
    - `success`：任务执行成功（短暂状态，完成后通常回到 idle）
    - `failed`：执行失败，需要上级介入
    - `blocked`：因外部依赖阻塞
    - `monitoring`：仅用于 chief_architect 等监控角色
